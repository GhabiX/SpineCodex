# SpineCodex 0.6.0

SpineCodex now tracks OpenAI Codex `rust-v0.170.0` at commit
`29eb79e9866b3262a777fdf8195c1b9e63684c91`. This updates the upstream
baseline from `0.164.0` and includes the upstream GPT-6.2 Sol and Astra catalog entries.

The npm product version is `0.6.0`. The CLI reports its Codex compatibility
version, `0.170.0`, with `spine-codex --version`.
